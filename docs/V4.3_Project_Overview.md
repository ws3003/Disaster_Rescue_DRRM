# Disaster_Rescue_DRRM V4.3 Project Overview

面向新队员的项目交接与代码阅读说明。系统为**灾害救援辅助系统**。

## 1. 项目定位

核心：Edge Perception(边缘感知) + Multimodal AI(多模态 AI) + Agent Decision(Agent 决策) + Human Interaction(人机交互)。

> 系统**辅助救援人员决策，不替代人工**；最终处置由人工决定。

## 3. Pi 端模块说明

| 文件 | 作用 |
|---|---|
| `src/detector.py` | YOLO26n 检测：帧 → 人员 bbox/类别（civilian/rescuer 视为人） |
| `src/pose.py` | MediaPipe 人体关键点：人体区域 → 33 关键点 |
| `src/state.py` | 五状态识别：Standing/Sitting/Lying/Fall/Help-Waving（几何规则+仲裁） |
| `src/risk.py` | DRRM 风险：状态/姿态 → risk_score(0~1) |
| `src/ranking.py` | 救援优先级：state→priority(HIGH/MED/LOW) + 排序 |
| `src/edge_perception.py` | 组合检测→姿态→状态→风险→排序 → person_events（人群过滤） |
| `src/edge_client.py` | Pi 主循环：采集→感知→上传 server→接回 llm_output→喂 Agent |

关系：`edge_client`(编排) → `edge_perception`(装配) → detector/pose/state/risk/ranking(算法)。

## 4. Server 端模块说明

- `server/api.py`：API 入口（/api/v1/analyze 等）。
- `src/vlm/`：Qwen-VL 调用（DashScope compatible-mode，API Key 经环境变量配置）。输入 图片；输出 `scene_type` / `overall_severity` / `hazards`。
- `src/llm/`：Qwen-LLM 调用（DashScope compatible-mode，API Key 经环境变量配置）。输入 `vlm_output` + `person_events`；输出 `event_summary` / `rescue_suggestions` / `task_proposals`。

> LLM 只生成建议，**不直接控制报警**；是否执行由 Agent 规则决定。

## 5. Agent 架构

`src/agent/`：

| 文件 | 职责 |
|---|---|
| `agent.py` | 入口（process_frame / ingest_llm_output / run_manual / run_heartbeat）、报警融合门 |
| `planner.py` | 规则/LLM 建议 → 生成 task.actions（白名单、≤3 步） |
| `executor.py` | 执行 actions：调工具、落库 |
| `memory.py` | 冷却门、record_alert、digest |
| `triggers.py` | 触发器（HIGH_RISK/STATE_CHANGE/Heartbeat 等） |

Agent 负责：接收感知结果、综合 LLM 建议、按规则约束、创建任务、执行工具。

> **LLM ≠ Agent**：LLM 提供建议（可能过度、不可靠）；Agent 通过规则/冷却/融合门决定真正执行（报警/记录/二次确认）。

## 6. SQLite 数据存储（重点，纠正误解）

**SQLite 属于 Agent 运行侧**——在**当前 Demo 中运行于 Raspberry Pi**：

- 运行于 Pi：Agent / Planner / Executor / Memory / SQLite。
- 数据库文件：由 `config` 中 `db.path` 配置决定，默认 `data/drrm.db`。
- 存表：`events`、`tasks`、`persons`、`agent_logs`。

用途：事件记录、任务记录、报警冷却、现场上下文查询（context_tool 只读 SQLite 供语音"现场怎么样"问答）。

## 7. 报警流程

```
Camera → YOLO → State → Risk → person_events
                          │
                          VLM/LLM Suggestions ──► 结合
                          │
Edge Risk + VLM/LLM Suggestions
  ↓
Agent Rule Fusion（_apply_alarm_fusion）
  ↓
Executor
  ↓
Communication Tool
  ↓
DingTalk
```
- `_apply_alarm_fusion`：person / environment 两类独立（`alert_type`）。
- 矩阵：无人+env HIGH→不报；person HIGH+env LOW→人员报警；person LOW+env HIGH→环境报警；HIGH+HIGH→两者；LOW+LOW→不报。

> 强调：**LLM 只提供建议，Agent 决定执行**（规则融合/冷却/二次确认）。
