## 5. 五个 S4 接口与 Session 的实际认证关系

### 5.1 当前 S4 认证代码

位置：B `server/s4.py:86`。关键代码原样摘录：

```python
token = (os.environ.get("S4_API_TOKEN") or "").strip()
if not token:
    raise S4Error(500, "INTERNAL_ERROR")
expected = f"Bearer {token}".encode("utf-8")
provided = (authorization or "").encode("utf-8")
if not authorization or not hmac.compare_digest(provided, expected):
    raise S4Error(401, "UNAUTHORIZED")
```

这里没有查询 sessions 表，没有调用 get_current_user，也没有把 Session 兑换为 S4 Token。

### 5.2 微信用户与媒体认证

- server/auth.py:131 login 接收 code，调用 server/wechat.py 的 WechatClient.code2session；WX_APPID/WX_APP_SECRET 只从服务端读取。
- server/auth.py:146–150 创建/复用用户，随机生成 Session Token，数据库存 SHA256，设置 86400 秒期限；登录响应返回 session_token/expires_in/user_id。

调用链：

```text
现有 A 的装配：页面 -> services/index.createDefaultService
```
