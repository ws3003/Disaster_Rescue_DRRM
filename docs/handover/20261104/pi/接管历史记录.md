## 优先缺口

1. **EdgeClient 共享摄像头入口没有注入上传器**：`src/edge_client.py::_build_e7e8` 实际传入 `uploader=None`。独立入口 `scripts/e7e8_runner.py` 有 `build_uploader` 和 `--storage/--uploader`。两种入口不能视为同一条已完成的录像上传链。
2. `config/edge.yaml` 的 `sensor.enabled`、`e8.enabled` 均为 false；默认配置不会启动整条传感器/取证链。硬件及测试配置确认前，不直接打开现场告警开关。
3. `config/x4.yaml` 的 `enabled=false`、`cloud_endpoint` 为空；真实云端验证需要服务地址和已验证的模型环境。
4. DS18B20 只能提供温度。湿度传感器来源未在本次接管中确认，不能用 Fake 湿度补齐真实验收。
5. S4 `/related` 仍返回 `media=[]`、`media_supported=false`。已有独立媒体接口不等于 A 线现有 S4 客户端已经支持媒体。
6. 微信用户 Session Token 与 S4 静态服务 Token 独立。不能把前者直接写进 A 线的 `s4_api_token` 当作联调完成。
7. 仓库中的旧审计报告对应更早提交，不能直接作为 `e1d75d6` 的测试和真机通过证明。
