# Disaster_Rescue_DRRM V0.1.5 终版报告 — 单帧灾害场景人员状态识别与救援优先级排序

- 日期：2026-09-04

- 本报告为 V0.1.5 全部工作的固化总结，不引入任何新实验或代码改动
- 数据来源：Step3 状态标定报告（[state_calibration_report.md](state_calibration_report.md)）、Step4 风险验证报告（[risk_validation_report.md](risk_validation_report.md)）、Step5 重标定报告（[risk_calibration_report.md](risk_calibration_report.md)）、[config/config.yaml](../config/config.yaml)、outputs/json/*.json 实测输出

## 0. 版本声明

V0.1.5 在 V0.1 完整单帧 pipeline 基础上完成展示增强与标定，**即日起冻结为稳定基线**：

- 输入：单张图片或图片目录（批量）；**不支持**视频/摄像头（V0.2）
- 时序能力：无 TSF、无 Static Lying、无动态 DRRM；F2–F5 时序因子 alpha=0 中性占位
- 不涉及树莓派/边缘部署（V1.0）
- 所有阈值为 **5 图 demo 标定的 AIC 展示基线**，非泛化指标

## 1. 系统架构

### 1.1 数据流

```
config.yaml
  → 读图 (单图 / 目录批量)
  → YOLO26n 灾害目标检测 (detector.py, models/disaster_best.pt)
  → 人员类别过滤 (civilian=1 进分析管线; rescuer=5 仅蓝框标注不参与排序; 动物灰框)
  → MediaPipe Pose 33 关键点 (pose.py, 按检测框 ROI 裁剪单人 static 推理)
  → 几何规则五状态分类 (state.py, 无模型, 纯关键点几何)
  → DRRM 单帧风险评分 (risk.py, R = F1 × F6; F2–F5 alpha=0 占位)
  → 救援优先级排序 (ranking.py, risk 降序 → STATE_ORDER → det_conf → pose_vis)
  → 可视化 (main.py: bbox + 骨架 + 状态/risk 标签 + 左上角 Top-K 排序榜)
  → JSON 结果落盘 (writer.py → outputs/json/<图片名>.json)
```

设备：`device.mode=auto`，有 CUDA 用 CUDA（实测 cuda / RTX 4060），否则 CPU。

| [pose.py](../src/pose.py) | MediaPipe Pose ROI 单人推理、33 关键点、visibility_mean | 未改 |

### 1.3 关键配置（config/config.yaml）

- YOLO：`models/disaster_best.pt`，conf_thres=0.35，iou_thres=0.45，imgsz=640；类别 0=cat, 1=civilian, 2=cow, 3=dog, 4=horse, 5=rescuer
- Pose：static_image_mode=true，model_complexity=1，ROI 扩边 roi_pad_ratio=0.2，min_person_box_h=40
- DRRM 状态先验 state_risk：**Fall 0.95 / Lying 0.90 / Help-Waving 0.78 / Sitting 0.55 / Standing 0.35**；w_min=0.25；alpha：f1=1.0，f2–f5=0.0（时序占位）
- priority 分级（代码常量，Step5 标定）：**HIGH ≥ 0.60 / MEDIUM ≥ 0.45 / LOW 其余**
- 可视化：骨架 + 状态 + risk + Top-5 排序榜

## 2. 已实现功能

**V0.1 核心（全部保留）**

1. YOLO26n 灾害目标检测（含动物/救援人员类别）
2. 人员类别过滤（civilian 进管线，rescuer/动物分流标注）
3. MediaPipe 33 关键点人体姿态估计（ROI 单人 static 推理）
4. 五类人体状态识别：Standing / Sitting / Lying / Fall / Help-Waving
5. DRRM 单帧风险评分（R = F1 × F6，F1 状态先验按置信度回归，F6 证据调制）
6. 救援优先级排序（risk 主键 + 状态危险序 tie-break）
7. 图片可视化输出（bbox + 骨架 + 状态 + 风险）

**V0.1.5 展示增强**

- 多图片测试：`--input` 支持单文件与图片目录批量（自动识别扩展名）
- JSON 结果输出：每张图 outputs/json/<名>.json（id/state/confidence/f1/f6/risk_score/priority/rank）
- Demo 优化：左上角半透明 Top-K 救援排序榜，风险分三色（HIGH 红 / MEDIUM 橙 / LOW 绿）
- 多人稳定化（Step1）：图内唯一 pid（按检测顺序），rank 通过 Detection 对象身份精确回填，修复同类多人错位；rescuer 蓝框仅标注、不做姿态/状态/风险、不进排序

**V0.1.5 标定（实验先行、最小改动）**

- Step3 状态标定：挥手阈值 WAVE_RATIO 0.45→0.25（实测挥手样本抬手比 0.27，非挥手样本 0.00）；坐姿新增尺度无关特征 vert_leg_ratio（髋-踝垂直跨距/躯干垂直长，阈值 1.1），解决轮椅遮挡下膝角失真
- Step5 风险标定：F6 由纯乘性腰斩 `clip(det_conf×vis, 0.25, 1)` 软化为 `0.5+0.5×raw`（∈[0.5,1.0]）；priority 阈值重标定为 0.60/0.45（方案 S3，四方案中唯一全部命中救援语义）

- **Lying**：本测试集失败原因在检测层（漏检）而非状态规则。

### 5.1 真实图片实测

| 图片 | state | conf | f1 | f6 | risk_score | priority |
|---|---|---|---|---|---|---|
| 004_help | Help-Waving | 0.35 | 0.599 | 0.810 | **0.485** | **MEDIUM** |
| 005_multi_person | Sitting | 0.65 | 0.532 | 0.763 | 0.406 | LOW |

跨图虚拟全局榜：#1 Help-Waving 0.485 MEDIUM → #2 Sitting 0.406 → #3–#5 Standing——主动求救者首次获得非 LOW 等级且居首。

### 5.2 五状态风险排序（合成证据，代表场景 conf=0.65、中证据 f6=0.80）

| 排名 | state | risk_score | priority |
|---|---|---|---|
| 1 | Fall | **0.634** | **HIGH** |
| 2 | Lying | **0.608** | **HIGH** |
| 3 | Help-Waving | 0.546 | MEDIUM |
| 4 | Sitting | 0.426 | LOW |

与设计危险序 **Fall > Lying > Help-Waving > Sitting > Standing** 完全一致。

### 5.3 分级可达性（标定后语义）

- Fall / Lying：中证据即 HIGH，弱证据保 MEDIUM（不漏判可能跌倒）；
- Help-Waving：稳定 MEDIUM；仅 conf=1 且中证据以上可达 HIGH；
- Sitting：上限 MEDIUM（conf=1 清晰帧 0.481），不进 HIGH；
- Standing：理论上限 0.35，恒 LOW。

## 6. 当前限制（如实固化）

1. **002 Fall 单帧不可分**：跌坐撑地姿态躯干角 10.3°、垂直压缩 1.65，与坐姿几何同源；单帧框架内继续降 LYING_ANGLE 对其无效且污染真实躺/倒判定。修复依赖 **V0.2 TSF 时序状态机**。
2. **003 Lying 检测层漏检**：高角度俯拍平躺人体 YOLO 零检测，state/risk 层不可达；需检测侧补充训练数据/检测阈值实验。
3. **HIGH 档无真实样本回归**：真实测试集无 Fall/Lying 进入风险层（002 误判、003 漏检），Fall/Lying HIGH 目前仅合成网格验证，需真实跌倒/躺卧图片回归。
4. **样本量**：全部阈值基于 5 张 demo 图（每类约 1 个正样本）标定，为 AIC 展示基线；正式标定需更多标注样本与网格搜索。
5. **004 state confidence 仅 0.35**：挥手几何裕度小（抬手比 0.27 vs 阈值 0.25），属 state 层话题；当前靠 F6 软化 + S3 使其进入 MEDIUM，state conf 提升后其 risk 自然升至 0.55~0.63。
6. **pose_vis 双重计入**：state confidence 与 F6 各使用一次可见度；F6 软化后该效应已大幅稀释，未改动，留待多样本复核。
7. **w_min=0.25 实际休眠**：F6 软化后自然下界为 0.5，w_min 仅作硬下限保留（配置兼容）。
8. **时序能力全部缺位**：F2–F5（转移/时长/活跃度/历史记忆）alpha=0 占位，Static Lying、动态 DRRM、视频/摄像头输入均为 **V0.2** 内容，本版本不实现；树莓派部署为 V1.0。
